## 1. 作品概念

一个"可漫游的中国古代夜空"。以宋代《新仪象法要》星表为数据底座，将三垣二十八宿体系、约 1400 颗古星还原为一张可缩放、可点击的交互星图网页。

核心叙事线：**"中国人如何给天空立法"**——肉眼观星 → 星官体系 → 圭表测影定节气 → 中西星空对话。

一句话定位：**不是天文科普文章，而是一件可以走进去的中国星空。**

## 3. 交互与技术亮点（评审给分点）

1. **真实星图投影**：使用星表赤经 / 赤纬数据，球面 → 平面投影采用**以北天极为中心的方位等距投影**（与苏州石刻天文图的制图方式一致，古意与算法兼得），投影算法为答辩技术亮点。
2. **星点闪烁引擎**：每颗星独立的闪烁周期（2.4s–7.6s 随机）、亮度区间（opacity 0.05–0.94）与尺寸层级（1px–2.25px），负延迟错峰启动，营造"呼吸感"夜空。
3. **滚动驱动叙事**：滚动进度经归一化（前 15% 为缓冲带）映射到星官点亮相位，逐层 reveal 带 0.5 偏移的吸附取整，"走到哪，亮到哪"。
4. **中西双星图对比**：同坐标系下两套连线体系实时切换 / 叠化，配左右滑块。
5. **圭表测影模拟**：太阳高度角 → 影长的简化为正弦年周期模型，交互参数真实可查。

## 4. 视觉方向

- **配色**（古籍金泥写本气质，避免科技蓝光）：
  - 底色：深夜墨蓝 `#162638`，渐变至近黑 `#0d0d11`
  - 星点与连线：哑光金 `#c9a227`，次级 `#af915f`
  - 正文文字：暖米金 `#fce1b6`（82% 透明度用于次级文字）
- **字体**：
  - 中文标题：古典书法感宋体（朱子古典类风格字）
  - 中文正文：黑体，保证屏读
  - 章节编号 / 图注：宽字距（letter-spacing 0.3em+）大写拉丁字母
  - 禁用中文斜体；中文强调用字重、描金、字距表达
- **材质**：纸张颗粒 + 墨渍纹理暗色叠加，模拟天文古籍拓片；不用玻璃拟态、不用蓝紫渐变。
- **图标**：手绘感内联 SVG，不用通用图标库 + 彩色圆角方块。

## 5. 技术架构

- **形态**：纯静态网站（无后端），一键部署 GitHub Pages / Vercel，满足大赛"提供可访问网站地址"要求。
- **栈**：Vite + TypeScript + Canvas 2D（星图渲染，千级星点性能充裕，不引入 WebGL 复杂度）+ D3-geo（投影与数据）+ GSAP ScrollTrigger（滚动叙事）。
- **数据**：星官坐标与星数取自公开古籍数字化数据集（《新仪象法要》 / 苏州石刻天文图相关开放数据），站内标明出处，满足大赛数据合规要求。
- **目录规划**（单仓库）：
  - `data/` 星表 JSON + 处理脚本（Python，一次性离线处理）
  - `src/starfield/` 星图渲染与投影
  - `src/sections/` 六章节组件
  - `src/ui/` 详情卡、滑块、导航
  - `public/` 字体、纹理
- **错误处理**：数据加载失败降级为静态示意星图；移动端降级为简化交互（章节卡片式）。
- **测试**：数据处理脚本有校验用例（星数、坐标范围）；页面以人工走查清单为主。

## 6. 内容与文案

- 《步天歌》原文为公有领域文本（丹元子），白话释义需自撰并核对。
- 史实表述（星官数量、圭表原理、紫微垣文化解读）需逐条核对来源，参考文献列入尾声页与作品说明书。

## 7. 分工与里程碑

- **AI 负责**：全部代码、数据处理、视觉实现、部署、说明文档与答辩 PPT 初稿。
- **用户负责**：通读文案、确认史实、试玩反馈。
- **里程碑**：
  1. M1 原型星图（能转能点，仅星野漫游章节）
  2. M2 六章节叙事版全量交互
  3. M3 内容定稿 + 移动端适配 + 性能走查
  4. M4 部署上线 + 参赛材料（说明书、演示视频、PPT）

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 当年命题口径变化 | 叙事模块化，主题口径集中在序章与尾声，便于替换 |
| 古籍星表数据质量参差 | 以单一权威数据源为准，异常星点人工标记而非强行修复 |
| 移动端评审体验 | 响应式降级方案内置，桌面优先但移动端可用 |
| 用户零基础导致验收困难 | 每个里程碑提供试玩地址 + 截图说明 |

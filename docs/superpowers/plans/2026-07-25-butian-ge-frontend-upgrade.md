## 1. 总体设计

### 1.1 体验概念

「从走进星空，到执球在手」。序章相机位于天球内部、以地面观星者视角仰视真实夜空；随滚动叙事推进，镜头逐渐拉远、抬升；到「天球仪」一章穿出球外，整片星空化为悬浮在古籍案头的 3D 天球仪——这一穿越瞬间是全场最强的「哇」时刻。之后岁差、东西对比均在球外视角展开。

### 1.2 技术栈变更

- **新增依赖**：`three`（WebGL 渲染）、`gsap`（ScrollTrigger 滚动叙事时间轴）。仅此两个，其余仍自实现。
- **保留不动**：`data/` 数据管线与三个 JSON 产物（stars 399KB / asterisms 40KB / western 20KB，gzip 后总量约 150KB，可接受）；vitest；圭表小组件的 2D Canvas 逻辑；降级页机制。
- **废弃**：`web/src/starfield/` 的 2D 渲染器（renderer/camera/projection/twinkle 等），其中坐标与岁差的纯函数逻辑改写为 3D 版本并保留测试。
- **渲染策略**：桌面端进入 WebGL 版；移动端与弱设备进入简化版（见 §6）。

### 1.3 新渲染架构 `web/src/sky3d/`

| 模块 | 职责 |
|------|------|
| `coords.ts` | ra/dec（度）→ 单位球面 Vec3；注意手性使球内仰视与实际星空一致；岁差改为绕黄极的旋转矩阵（比 2D 近似更正确）。纯函数，配 vitest |
| `StarField.ts` | `THREE.Points` + 自定义 ShaderMaterial：星等 → 尺寸/亮度，每星闪烁相位/频率作为 attribute（保留 mulberry32 确定性种子），加色混合，亮星星芒 sprite |
| `ConstellationLines.ts` | 星官/西方星座连线 `LineSegments`，按分组挂载 highlight uniform，支持逐组点亮/熄灭动画 |
| `Labels.ts` | CSS2DRenderer 渲染星官名（约 309 个，按视锥/距离剔除），悬停星点显示星名；字体走古籍视觉系统 |
| `post.ts` | EffectComposer + UnrealBloomPass（半分辨率），辉光阈值随章节可调 |
| `CameraRig.ts` | GSAP 驱动的相机动轨：每章一组关键帧（位置/朝向/FOV），球内→球外穿越曲线；同时驱动天空 uniform（高亮组、透明度、bloom 强度） |
| `ArmillarySphere.ts` | 球外视角的天球仪：经纬网格环、地平环、可惯性旋转，古籍黄铜质感材质 |
| `interaction.ts` | 球内拖拽环视 / 球外轨道旋转，Raycaster 命中星点 → 详情卡；保留星光引力环光标 |
| `quality.ts` | 性能自适应：DPR 上限 2、掉帧时降 bloom/星数；WebGL 不可用 → 降级页 |

### 1.4 滚动叙事（GSAP ScrollTrigger）

废弃自研 `scroll/scrollManager.ts`，改用 ScrollTrigger：每章一个 pinned section + scrub 时间轴，驱动 CameraRig 关键帧插值与 DOM 面板进出。滚动进度与相机/天空状态完全由时间轴声明式描述，章节调试就是调时间轴。

### 1.5 章节重构方案（八章骨架保留）

| # | 章节 | 视角 | 升级要点 |
|---|------|------|----------|
| 1 | 序章 | 球内仰视 | 夜空缓慢周日旋转，bloom 呼吸感；标题随滚动描金浮现；环境音入口在此首次提示 |
| 2 | 星野漫游 | 球内仰视 | 三垣四象按滚动分区点亮（3D 高亮 + 连线生长动画）；自由探索拖拽环视/点击星官详情卡（《步天歌》原文+白话） |
| 3 | 观象授时 | 球内（地景） | 圭表组件保留逻辑、视觉重制为古铜/石圭质感；拖动日影联动节气，背景天空随季节实时换星野 |
| 4 | 天人之间 | 球内→推近 | 镜头推向紫微垣，北极五星逐一点名；「斗为帝车」北斗旋转演示 |
| 5 | 天球仪 | **穿出球外** | 全场高潮：镜头穿越球面，星空化为案头黄铜天球仪，可拖拽惯性旋转 |
| 6 | 岁差一万年 | 球外 | 时间机自动播放：天球绕黄极进动，北极星在帝星→勾陈一→织女间更替，年份刻度同步 |
| 7 | 东西对话 | 球外 | 中西连线双体系叠化，左右滑块对比典型案例（天狼/织女/北斗） |
| 8 | 尾声 | 球外渐远 | 天球仪渐远化为一点，落版署名（HYG CC BY-SA-4.0 + Stellarium + 素材署名） |

文案全部重写：每章「一句钩子 + 三两行正文」，砍掉说明书式段落。

### 1.6 古今融合视觉系统

- **字体**：标题用开源书法/宋体（候选：思源宋体 Heavy、演示悠然小楷、江西拙楷——引入前逐一核实许可，不确定的问用户）；正文思源黑/系统黑体。中文 webfont 必须做子集化（仅所用字形，控制在 200KB 内）。
- **UI 质感**：保留朱砂印、eyebrow 宽字距拉丁、竖排标题；纸张颗粒与墨渍纹理程序化生成（SVG feTurbulence，现有方案延伸）；描金细节。
- **星空侧**：写实向——微弱星光色温差异（B/A/F/G/K 型星偏色）、bloom 辉光、银河带淡入（程序生成噪声带，不引外部贴图）。

### 1.7 音频

`web/src/audio/ambient.ts`：Web Audio 图——滤波噪声底 + 缓慢正弦铺底 + 偶发古琴泛音（CC0 采样或程序合成）。**默认静音**，序章出现明显的开启开关；页面隐藏时自动暂停。素材许可逐条登记进尾声页。

## 3. 移动端简化版

- 判定：coarse pointer / 小屏 / WebGL 性能弱 → 动态 import 不加载 `sky3d`，改载静态星空海报（构建期用桌面端离屏渲染一张 2K 星空图入库）+ 章节卡片式滚动。
- 同一套 HTML/文案，保证内容完整可读；交互组件（圭表滑杆、对比滑块）保留 2D 版。

## 4. 风险与对策

| 风险 | 对策 |
|------|------|
| three.js 体积 | tree-shaking + 桌面端动态 import；gzip 后约 150KB 可接受 |
| 中文 webfont 体积 | 子集化（fontmin / 中文网字计划），只打包用到的几百字 |
| 309 个标签性能 | CSS2D + 视锥/距离剔除，同屏上限几十个 |
| ScrollTrigger 与 fixed canvas 兼容 | 成熟方案，POC 阶段（P0）先行验证 |
| 岁差 3D 化正确性 | 绕黄极旋转矩阵，配 vitest 与已知历元对照 |
| 素材版权 | 引入前逐条核实（字体 OFL/免费可商用、音频 CC0），存疑项问用户，尾声页统一署名 |
